# 마작 궤도 (mahjong_player_map)

그릴마당 마작 대국 기록으로 플레이어별 성향 지표를 계산하고, 성향이 닮은 사람끼리 가깝게 놓이도록 3D 공간에 펼친 지도입니다. 내 이름을 검색하면 가까운 사람, 정반대인 사람, 실제 대국에서의 관계(단짝·라이벌)를 보여줍니다.

- `pipeline/`: 로컬에서 돌리는 오프라인 파이프라인. 대국 기록을 읽어 `web/data/player_map.json`을 만듭니다.
- `web/`: 정적 페이지(three.js). madang_web이 `/player_map/`으로 서빙하며, 운영 서버에는 이 폴더만 있으면 됩니다.

## 데이터 갱신

```bash
cd mahjong_player_map
pip install -r pipeline/requirements.txt

# 1) 대국 기록 수집 (둘 중 하나)
python -m pipeline.fetch_data --db ../games.db                          # 내려받은 DB 파일
python -m pipeline.fetch_data --base-url https://<계정>.pythonanywhere.com  # 운영 API

# 2) 지도 생성 → web/data/player_map.json
python -m pipeline.build

# (선택) 군집·가중치 탐색 리포트 → data/explore_report.md
python -m pipeline.explore --k 7
```

수집 단계에서는 라이브 게임, 모든 시즌 아카이브, 대회 기록을 합칩니다. `TEST` 아카이브는 빼고, (시간, 이름, 점수)가 같은 게임은 하나만 남깁니다.

## 방식 요약

- **대상:** 20판 이상인 플레이어로 지도와 군집을 학습합니다. 10~19판인 플레이어는 학습된 지도 위에 투영해 "관측 중"으로 표시합니다.
- **특징 25개 (5개 그룹):**
  - 착순: 톱률, 2착률, 3착률, 라스율
  - 점수: 점수 기복, 대톱률(5만점+), 토비율, 원점 부근 종국률(2~3만점), 톱 시 평균 점수, 라스 시 평균 점수
  - 흐름: 연속 연대율(3연대+), 라스 후 회복, 순위 추세
  - 대국 습관: 시간대 3구간, 주말 대국, 연속 대국 빈도, 연속 대국 길이, 최다 연속 대국 (3시간 이내 3판 이상을 연속으로 침)
  - 동탁: 동탁자 다양성, 최다 동탁자·Top3·Top5 비중, 동탁자 실력
- **보정과 가중치:**
  - 비율은 경험적 베이즈로 전체 평균 쪽으로 수축합니다(사전 강도 10판).
  - 특징은 z-score로 표준화한 뒤 그룹별 가중치를 곱합니다(착순 0.4, 점수 1.0, 흐름 0.7, 대국 습관 0.5, 동탁 0.5). 실력보다 성향이 위치를 정하게 하려는 것이며, 실력(평균 pt)은 점의 밝기로 따로 표시합니다.
- **지도:** PCA(10차원)로 줄인 뒤 UMAP으로 3D 좌표를 만듭니다. 군집은 KMeans(k=10)이며 화면에는 이름 없이 무리 중심의 작은 별로만 나타납니다. 닮은꼴은 축소 전 공간의 코사인 유사도로 고릅니다.
- **관계:** 같은 판에서 누가 더 높은 순위였는지로 정합니다.
  - 단짝: 가장 많이 동탁한 사람
  - 라이벌: 8판 이상 동탁했고 내가 위였던 비율이 50±5%
